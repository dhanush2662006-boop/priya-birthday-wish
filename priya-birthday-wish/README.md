# Priya Mahh Birthday Website

A responsive, single-page birthday surprise website.

## Run locally
1. Extract this ZIP.
2. Open the `priya-birthday-wish` folder in VS Code.
3. Open `index.html` in a browser (or use the Live Server extension).

## Publish with GitHub Pages
1. Create a public GitHub repository named `priya-birthday-wish`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open Settings → Pages.
4. Choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

No local image assets are required. Google Fonts are loaded online; the site falls back to system fonts if unavailable.
